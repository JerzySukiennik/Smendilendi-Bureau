# The avatars

Three rigged low-poly people, one GLB per body build, generated by
`tools/blender/avatar/build-avatars.py` and audited by
`tools/blender/avatar/verify-avatar.mjs`. Nothing here is modelled by hand: a
change to a body, a garment or a clip is a rebuild.

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/blender/avatar/build-avatars.py -- --out assets/avatars
node tools/blender/avatar/verify-avatar.mjs
open http://localhost:5179/tools/avatar-preview.html      # and LOOK at it
```

The runtime is `src/office/avatar.js`; its header is the API contract. This file
is the data contract.

## Files

| file | bytes | what |
|---|---|---|
| `avatar-slim.glb` | 843 kB | 1.740 m stature |
| `avatar-regular.glb` | 844 kB | 1.770 m stature |
| `avatar-broad.glb` | 842 kB | 1.795 m stature |
| `Nunito-Bold.ttf` | 125 kB | the nick plaque face (SIL OFL 1.1, see CREDITS.md) |

Total payload **2.59 MB**, against a 6 MB budget. A session loads only the
builds its players actually chose.

## The spec space

A player is one row from each column. 3 x 3 x 3 x 2 x 6 x 2 x 2 = **1296
silhouettes** before colour, and the six tint slots are free 24-bit values.

| axis | values |
|---|---|
| `build` | `slim`, `regular`, `broad` |
| `top` | `tshirt`, `shirt`, `hoodie` |
| `bottom` | `tracksuit`, `chinos`, `skirt` |
| `shoes` | `trainers`, `boots` |
| `hair` | `short`, `buzz`, `bob`, `long`, `bun`, `curly` |
| `cap` | on / off — reads right over `short` and `buzz` |
| `glasses` | on / off |

The body build is the one axis that is a different FILE. Everything else is a
visibility flip inside the file the player already has, so changing an outfit in
the character screen costs nothing and needs no network round trip beyond the
spec itself.

## Meshes in the file

Every wardrobe piece ships in every GLB and the runtime shows the ones the spec
names. Two of them are conditional skin, not clothing:

* `body_arms` — bare forearms, shown ONLY under `tshirt`
* `body_legs` — bare shins, shown ONLY under `skirt`

5980 triangles sit in the file; **1884 to 3036 are ever visible at once**, and
the default outfit (hoodie / tracksuit / trainers / short hair) is 2668. The
heaviest wearable combination is hoodie + tracksuit + trainers + curly + glasses.

A GLTFLoader note that bites: a mesh with two material slots is split on import
into `name_1` and `name_2`, so `top_hoodie` arrives as two objects. The runtime
strips the `_<digit>` suffix and treats a piece as a list.

## Tint slots

Five material slots are near-white and take the player's colour by
multiplication; two are fixed detail colours nobody tints.

| material | what wears it | tinted by |
|---|---|---|
| `skin` | face, neck, hands, bare arms and legs | `setTint('skin', …)` |
| `tint_top` | the whole top, sleeves, hood, pocket | `setTint('top', …)` |
| `tint_bottom` | trousers, skirt, waistband | `setTint('bottom', …)` |
| `tint_shoes` | the shoe upper | `setTint('shoes', …)` |
| `tint_hair` | every hairstyle | `setTint('hair', …)` |
| `tint_extra` | the cap | `setTint('extra', …)` |
| `dark` | eyes, brows, mouth, boot soles, glasses frames | fixed `#2B2825` |
| `light` | trainer soles, drawstrings, the tracksuit stripe | fixed `#F3ECE1` |

`bottom_skirt` gets its own two-sided clone of `tint_bottom` in the runtime: the
skirt is an open cone and a swinging leg passing through a single-sided surface
reads as a tear.

## Clips

Exported as named glTF animations, sampled at 30 fps.

| clip | length | loops | what it is |
|---|---|---|---|
| `idle` | 4.00 s | yes | standing, breathing, a weight shift and a look-off |
| `walk` | 1.00 s | yes | two steps, authored for **1.10 m/s** |
| `sit` | 3.20 s | no | standing → seated on a 0.45 m seat; holds the last frame |
| `sit_idle` | 2.40 s | yes | the seated hold, breathing — play after `sit` |
| `type` | 2.00 s | yes | seated, forearms on a 0.74 m desk, fingers moving |
| `wave` | 1.60 s | no | a greeting from standing; holds, then cross-fade back to `idle` |

`walk` is authored **in place**: drive the group forward at 1.10 m/s (or scale
`timeScale` by your speed over 1.10) and the feet stay planted.

## Skeleton — 33 bones

Underscores, never dots: three.js strips `.` from node names when it binds
tracks, so `thigh.L` would silently become `thighL`.

```
hips
├─ spine ─ chest ─ neck ─ head
│   ├─ shoulder_L ─ upperarm_L ─ forearm_L ─ hand_L ─ fingersA_L ─ fingersB_L
│   └─ shoulder_R ─ upperarm_R ─ forearm_R ─ hand_R ─ fingersA_R ─ fingersB_R
├─ thigh_L ─ shin_L ─ foot_L          thigh_R ─ shin_R ─ foot_R
├─ hem_F, hem_B                       (hoodie hem)
├─ pant_up_L/R, pant_lo_L/R           (trouser legs)
└─ skirt_F, skirt_B, skirt_L, skirt_R (skirt panels)
```

The last ten are **cloth bones**. They carry no animation an animator authored:
their rotation is a damped spring integrated offline against the parent limb's
angular acceleration, so the fabric lags the leg and overshoots it. The driver
is the thigh angle measured from the clip's own mean, not the raw angle — a
seated thigh sits at 85 degrees for a whole clip, and driving off the raw angle
threw the hoodie hem out over the lap and held it there.

Attach points a gameplay system may want: `head` (a hat, a camera), `hand_R`
(a mug, a rolled drawing), `chest` (a name badge). The nick plaque is not
parented to a bone — put it in the avatar's group at `NICK_Y` = 2.02 m.

## What the audit measures, and the numbers it currently prints

`verify-avatar.mjs` parses the GLB by hand and skins the vertices itself, so a
build cannot pass because the tool that wrote it also read it back.

| measurement | slim | regular | broad |
|---|---|---|---|
| stature, dressed, tallest hairstyle | 1.740 m | 1.770 m | 1.795 m |
| worn triangles, min..max | 1884..3036 | 1884..3036 | 1884..3036 |
| foot slide along travel | 0.4 mm | 0.3 mm | 0.3 mm |
| foot slide sideways | 1.4 mm | 1.4 mm | 1.4 mm |
| trouser hem swing, peak-to-peak | 225 mm | 226 mm | 227 mm |
| hoodie hem swing, peak-to-peak | 32 mm | 31 mm | 31 mm |

**Foot slide** is the residual after fitting the ideal constant velocity across
the stance — what a player would see once the group moves at the authored speed.
**Hem swing** is the distance between each cloth vertex skinned normally and the
same vertex with the cloth bones held at their bind rotation, taken peak to peak
across the walk: the motion the leg does not account for.

The audit fails the build if a stature leaves 1.70-1.80 m with any hairstyle on,
or if the heaviest wearable outfit passes 3200 triangles.
