# Dev server

Port **5179**. Start it with the browser preview tool: `preview_start {name:"game"}`.

`http://localhost:5179/`          — the game
`http://localhost:5179/progress/` — the live build progress page

Do NOT use port 5178: another project (Voidworks) has a live server there and a
teammate may have a session running on it. Never restart or connect to it.
